# storage-report

Reporte visual de uso de disco con servidor web dinámico, auto-refresh y kiosk mode.

## Instalación rápida

```bash
curl -sSL https://raw.githubusercontent.com/<user>/storage-report/main/scripts/install.sh | bash
```

## Uso

- Servicio: `systemctl --user status storage-report`
- App: `storage-report` desde el menú
- URL: http://localhost:8888
